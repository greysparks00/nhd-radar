# Radar: An Innovation That Changed Defense

A temporary National History Day class project about radar, World War II, and radar's lasting impact.

This is a plain HTML/CSS site with seven pages. It has no JavaScript, animations, build step, or external dependencies.

## View the site

Open `index.html` locally, or visit the GitHub Pages URL shown in this repository's About section.

## Edit the site

Edit the corresponding HTML file to change a page. Edit `style.css` to change the font or layout. Pushing changes to `main` updates GitHub Pages.

The full annotated bibliography is on the Research page. Quotes have credits beside them. The existing process paper and multimedia have not been added to this draft.

GitHub Pages publishes from the root of the `main` branch. `.nojekyll` serves these files directly.
